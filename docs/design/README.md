# Design passes

One file per system, written before implementation (see CLAUDE.md). Template:

```
# <System> design
Status: draft | reviewed | implemented
Pillars served: P1–P5
Player fantasy: two sentences
Rules: the mechanics, as data where possible (tables of numbers)
Inputs and feedback: what the player presses and sees
Multiplayer: what is synced, what is per player
Scope: Slice / MVP / Tiers 2–3 / v1.0 / Later
Open questions
```

Planned: `boss-i.md` (M1, after the Tier 1 design session), `magic.md` and `healer.md` (M2, before any magic code), `guns.md` (M4).
