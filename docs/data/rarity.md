# `sb:rarity`

Datapack registry declared by `sb_core`; read by `sb_gear` (item tooltips and colours), the reforge NPC (cost) and loot tables (drop weight). Files live at `data/<namespace>/sb/rarity/<name>.json`. Loaded with the world. Rarity affects reforge cost and drop weight, never raw power (PRD 3.12): a Rare weapon is a good weapon of its tier, a rainbow one has a unique move.

## Shape

```json
{
  "color": "#5555ff",
  "order": 2,
  "reforge_cost_multiplier": 1.5,
  "rainbow": false,
  "tooltip_key": "rarity.sb_core.rare",
  "icon": "sb_core:rare"
}
```

| Field | Type | Default | Meaning |
|---|---|---|---|
| `color` | `"#RRGGBB"` | required | Name colour. Written and read as a hex string; a plain RGB integer without alpha in Java. |
| `order` | int | required | Position in the ladder, lowest first, unique across entries. Comparisons ("at least Rare") use this, never the id. Order 0 is *below* common: a rarity can be a penalty. |
| `reforge_cost_multiplier` | float | required | Multiplies the tier's `reforge_base_cost` when reforging an item of this rarity. |
| `rainbow` | boolean | `false` | The name cycles through the spectrum instead of sitting at `color`. Reserved for the top rarity; `color` stays the fallback for chat, logs and anywhere that cannot animate. |
| `tooltip_key` | string | `rarity.<namespace>.<path>` | Lang key of the rarity line in the tooltip. |
| `icon` | sprite id | none | Sprite shown beside the name, so colour is never the only signal (accessibility). Absent until the art exists. |

## The ladder (decision 0022)

| Rarity | Order | Colour | Reforge cost | Meaning |
|---|---|---|---|---|
| `bad` | 0 | grey `#808080` | ×0.75 | A worse item than it was. Reforging is a gamble, so a roll must be able to disappoint. |
| `common` | 1 | white `#ffffff` | ×1.0 | The baseline. |
| `rare` | 2 | blue `#5555ff` | ×1.5 | |
| `epic` | 3 | purple `#aa55ff` | ×2.0 | |
| `legendary` | 4 | orange `#ffaa00` | ×3.0 | |
| `mythic` | 5 | rainbow (fallback `#ff55ff`) | ×4.0 | Reserved for one-of-a-kind items with a unique move or mechanic. |

`sb_core` ships all six, generated by `./gradlew :sb_core:runData`. Cost multipliers are first-pass slice values; tune them in `SbCoreEntries.rarities`, never in the generated JSON.

## Read by

`sb_gear` (tooltips, loot), `sb_hub` (reforge cost), `sb_core` (`sb:reforge_modifier` entries name a rarity).
