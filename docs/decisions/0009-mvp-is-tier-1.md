# 0009 — MVP is Tier 1 complete: one boss, all five classes
Date: 2026-09-04
Status: accepted
Context: the user wants magic and healer in the MVP and does not want later-tier bosses or accessories designed yet: "focus on the Tier 1 MVP".
Decision: vertical slice = the Tier 1 loop with melee and bow. MVP = Tier 1 complete with all five classes (melee, ranged, magic, summoner, healer), boss loot bags, heart shards, combining, five NPCs, potions and scalable difficulty, against the same single boss. Guns land in v1.0. The magic and healer design pass is a Milestone 2 deliverable that precedes their implementation. Nothing beyond Tier 1 is designed until the MVP is fun.
Consequences: the PRD scope tables have columns Slice / MVP / Tiers 2–3 / v1.0 / Later; Tier 2+ settings, bosses, unlocks and kit stay placeholders.
